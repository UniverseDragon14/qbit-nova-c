# Universal Dragon Aslam

Universal Dragon Aslam is building QBIT NOVA C, a C-based quantum-style software runtime for classical hardware.

QBIT NOVA C is not a physical quantum computer. It is a software runtime that explores quantum computing concepts through simulation, virtual QCPU layers, Bell-state proof tests, and OpenQASM export.

## Main focus

- C-based quantum-style runtime
- software virtual QCPU
- state-vector simulator
- Bell-state proof
- OpenQASM bridge
- Raspberry Pi 5 and classical Linux runtime
- Universal Dragon ecosystem direction

## Safety boundary

QBIT NOVA C does not claim that a Raspberry Pi, phone, or laptop becomes a real quantum chip.

It stays inside software simulation, safe research, and public technical proof.

# What is QBIT NOVA C?

QBIT NOVA C is a C-based quantum-style software runtime created by Universal Dragon Aslam.

It runs on classical hardware such as Raspberry Pi 5 and normal Linux systems.

It includes:

- `.qn` language direction
- lexer, parser, AST, compiler
- bytecode VM
- 2-qbit state-vector simulator
- Hadamard and CNOT simulation
- Bell-state proof runner
- virtual QCPU / QMSG software layer
- OpenQASM export bridge
- CI proof tests
- hardware safety boundary checks

## What it is not

QBIT NOVA C is not a physical quantum computer.

It does not convert Raspberry Pi, phone, or laptop hardware into a real quantum chip.

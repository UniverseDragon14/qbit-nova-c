# Universal Dragon Ecosystem

Universal Dragon is the wider ecosystem direction created by Aslam.

## Main roles

- `qbit-nova-c`: C runtime and quantum-style simulation proof layer
- `Universal-Dragon-Core`: ecosystem source of truth, `.ud` direction, documentation, and safety-control layer
- NOVA / NovaKutty: core brain direction
- EVE: assistant and app-builder direction
- UDOS: operating/control layer direction

# Raspberry Pi 5 Runtime

QBIT NOVA C can run on Raspberry Pi 5 and other classical Linux systems.

The Raspberry Pi 5 is used as a compact development and proof machine for:

- C runtime testing
- state-vector simulation
- Bell-state proof runs
- OpenQASM export
- virtual QCPU boundary checks

## Boundary

Raspberry Pi 5 does not become a physical quantum computer.

It runs the QBIT NOVA C software runtime on classical CPU hardware.
